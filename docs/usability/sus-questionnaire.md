# Instrumen Kuesioner System Usability Scale (SUS)

## 1. Petunjuk Pengisian untuk Partisipan

Kuesioner ini bertujuan untuk mengukur kebergunaan (*usability*) dan kemudahan penggunaan aplikasi **Simple Sales** berdasarkan pengalaman langsung yang baru saja Anda lakukan.

**Prinsip Pengisian:**
1. Pengujian ini mengevaluasi **sistem**, bukan menguji kemampuan pribadi Anda.
2. Isilah kuesioner ini secara mandiri dan jujur sesuai persepsi atau impresi pertama Anda setelah menyelesaikan seluruh skenario tugas.
3. Jangan meluangkan waktu terlalu lama pada satu pernyataan; tanggapan spontan biasanya paling akurat menggambarkan pengalaman Anda.
4. Berikan penilaian pada setiap butir pernyataan dengan memilih angka skala **1** sampai **5**:
   - **1** = Sangat Tidak Setuju (STS)
   - **2** = Tidak Setuju (TS)
   - **3** = Ragu-ragu / Netral (N)
   - **4** = Setuju (S)
   - **5** = Sangat Setuju (SS)
5. Seluruh butir pernyataan (Q1 s/d Q10) wajib diisi tanpa ada butir yang terlewat.

## 2. Butir Pernyataan Kuesioner (Bilingual)

> [!NOTE]
> Rumusan butir Bahasa Indonesia menggunakan adaptasi baku Sharfina & Santoso (2016) dari instrumen asli John Brooke (1996). Karena naskah fisik proposal penelitian tidak tersimpan di repositori, adaptasi akademik ini dijadikan rujukan resmi yang valid dan teruji.

| No | Pernyataan (Bahasa Indonesia) | Statement Reference (English) | Polaritas | Rumus Konversi |
| :---: | :--- | :--- | :---: | :---: |
| **Q1** | Saya merasa akan sering menggunakan sistem ini. | *I think that I would like to use this system frequently.* | Positif (+) | $R_1 - 1$ |
| **Q2** | Saya merasa sistem ini terlalu rumit untuk digunakan. | *I found the system unnecessarily complex.* | Negatif (-) | $5 - R_2$ |
| **Q3** | Saya merasa sistem ini mudah untuk digunakan. | *I thought the system was easy to use.* | Positif (+) | $R_3 - 1$ |
| **Q4** | Saya merasa membutuhkan bantuan dari orang teknis untuk dapat menggunakan sistem ini. | *I think that I would need the support of a technical person to be able to use this system.* | Negatif (-) | $5 - R_4$ |
| **Q5** | Saya merasa berbagai fungsi dalam sistem ini terintegrasi dengan baik. | *I found the various functions in this system were well integrated.* | Positif (+) | $R_5 - 1$ |
| **Q6** | Saya merasa terdapat terlalu banyak ketidakkonsistenan pada sistem ini. | *I thought there was too much inconsistency in this system.* | Negatif (-) | $5 - R_6$ |
| **Q7** | Saya merasa sebagian besar orang akan dapat mempelajari sistem ini dengan sangat cepat. | *I would imagine that most people would learn to use this system very quickly.* | Positif (+) | $R_7 - 1$ |
| **Q8** | Saya merasa sistem ini sangat membingungkan / kaku saat digunakan. | *I found the system very cumbersome to use.* | Negatif (-) | $5 - R_8$ |
| **Q9** | Saya merasa sangat percaya diri saat menggunakan sistem ini. | *I felt very confident using the system.* | Positif (+) | $R_9 - 1$ |
| **Q10** | Saya merasa perlu mempelajari banyak hal terlebih dahulu sebelum dapat menggunakan sistem ini. | *I needed to learn a lot of things before I could get going with this system.* | Negatif (-) | $5 - R_{10}$ |
